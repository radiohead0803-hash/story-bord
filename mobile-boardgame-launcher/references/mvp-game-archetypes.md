# Lightweight Board Game Archetypes

## Dice Path Game
- 주사위로 이동하고 칸 이벤트를 해결한다.
- 가장 쉬운 MVP 구조다.
- 추천 수익화: 보상형 광고, 스킨, 광고 제거.

## Card Movement Board
- 주사위 대신 카드로 이동 수를 정한다.
- 전략성이 약간 높다.
- 추천 수익화: 카드 스킨, 특수 카드 팩.

## Tile Puzzle Board
- 보드 타일을 뒤집거나 연결해 보상을 얻는다.
- 퍼즐 감성이 강하다.
- 추천 수익화: 힌트, 추가 턴, 테마팩.

## Mini Mission Board
- 각 칸에서 5-10초 미니미션을 수행한다.
- 재미는 높지만 구현 난이도가 상승한다.
- MVP에서는 미니미션 수를 3개 이하로 제한한다.
