# Character Worldbuilding

Use this when creating mascot concepts for student sticker and promotional goods brands.

## Character card template

| Field | Required content |
|---|---|
| character name | Korean name, easy to say, not protected/famous |
| role | why the character exists for students and buyers |
| silhouette | one recognizable shape at 15-20 mm sticker size |
| signature item | one item only: star badge, stamp, pencil, checklist, backpack |
| personality | 3 traits max |
| catchphrase | short Korean phrase without guaranteed learning outcome |
| expression set | 칭찬, 응원, 집중, 완료, 감사, 실수해도괜찮아, 미션성공 |
| pose set | 정면, 손흔들기, 스티커 들기, 체크 가리키기, 점프, 집중 |
| product path | sticker, board, card, package, thumbnail, SNS |
| avoid | famous characters, copied proportions, school logo, celebrity feel |

## Strong character rules

- Use 2-3 identifiers total. More details reduce print quality.
- Prefer rounded simple shapes and thick outlines.
- Create a system, not a one-off mascot: expression set, pose set, color rules, phrase rules.
- Keep emotional use scenes: reward, habit, class mission, study check, gratitude.
- Do not imitate a named franchise or platform mascot.

## Example structure

```markdown
## 반장이
- Role: 아이의 작은 미션 완료를 칭찬해주는 교실 친구
- Silhouette: 둥근 얼굴 + 별 배지
- Item: 칭찬 도장
- Personality: 밝음, 성실함, 약간 장난기
- Catchphrase: 오늘도 한 칸 성공!
- Expressions: 칭찬/응원/집중/완료/감사/괜찮아/미션성공
- Products: 칭찬스티커, 미션카드, 네임라벨, 학급쿠폰
```
