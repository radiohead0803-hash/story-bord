# Scoring Rubric

## Name score

| Metric | High score means |
|---|---|
| 기억 용이성 | 3-6 Korean syllables, easy to recall, distinctive sound |
| 발음/리듬감 | natural Korean rhythm, easy for children and parents |
| 검색/썸네일 식별성 | not too generic, readable in thumbnail, easy exact search |
| 초등학생 친화성 | friendly and playful without being childish for buyers |
| 학부모/교사 신뢰감 | safe, educationally appropriate, not scammy or exaggerated |
| 카테고리 적합성 | immediately suggests stickers, stationery, rewards, class goods |
| 확장성 | can expand to stickers, labels, cards, events, seasonal goods |
| 캐릭터화 가능성 | can become a mascot or world with repeatable characters |
| 시장성 근거 | supported by keyword, competitor, price, and buyer-fit data |
| IP 리스크 낮음 | no obvious trademark/copyright/famous-character conflict |

## Character score

| Metric | High score means |
|---|---|
| 귀여움 | emotionally appealing to children and acceptable to parents |
| 독창성 | not generic or franchise-like |
| 실루엣 | recognizable at sticker size |
| 인쇄 단순성 | thick lines, few details, high contrast |
| 표정 확장성 | can produce 5-7 consistent expression variants |
| 굿즈 확장성 | works across sticker, card, package, thumbnail, SNS |
| 연령 적합성 | fits preschool/elementary without babyish or teen mismatch |
| 감정/사용장면 | clear use in reward, habit, study, class-event scenes |
| IP 리스크 낮음 | no protected style/character similarity |

## Suggested interpretation

- 82+: strong candidate if evidence exists.
- 72-81: good prototype candidate; complete research and visual proof.
- 68-71: needs revision or more evidence.
- under 68: do not prioritize.
- any high IP risk: blocked regardless of total score.
