# Candidate Style Guide

## Good naming lanes

1. 칭찬/보상: 칭찬, 별, 한칸, 미션, 성공, 참잘
2. 학교/문구: 교실, 알림장, 문구, 학급, 반장
3. 캐릭터/세계관: 반장이, 체크몽, 도장깨비, 별친구
4. 제작소/디자인랩: 문구랩, 굿즈연구소, 교실상점
5. 프리미엄/선물: 반짝선물, 하루상자, 칭찬박스

## Avoid

- famous IP terms
- generic names like 스티커샵 or 문구스토어
- claims that promise grades, therapy, or guaranteed behavior change
- names too long for a mobile thumbnail
- names difficult for children to repeat

## Good character directions

- 반장이: reliable student leader with a star badge
- 체크몽: friendly checklist monster with one simple shape
- 도장깨비: stamp goblin, but must be original and not franchise-like
- 별친구: star-badge buddy for reward moments
- 미션콩: small bean-like mission helper
